# JohnnyAI

Persönliches Windows-Tool zur Aufnahme, Transkription und automatischen Zusammenfassung von Meetings.

Dieses Repository dient ausschließlich als öffentlicher Ablageort für Versionsinformationen (`version.json`) und Releases, damit die App selbstständig auf neue Versionen prüfen kann. Der Quellcode ist nicht Teil dieses Repos.
